# Cuoteo

Aplicación web para dividir gastos grupales en eventos, salidas, viajes o reuniones. Elimina cálculos manuales y transferencias de más: muestra deudas netas y facilita el cobro en Perú (Yape, Plin, CCI). Hay usuarios registrados y “fantasmas” (solo nombre, sin cuenta).

Stack: Next.js (App Router), TypeScript, Prisma, Tailwind CSS, Clerk, Resend. Moneda PEN. Zona horaria `America/Lima`.
